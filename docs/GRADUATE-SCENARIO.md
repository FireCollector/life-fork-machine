# TASK-037｜读研选择场景验收记录

## 场景是什么

第二个正式可玩场景是“继续工作，还是辞职准备读研？”。它不把读研当作一张自动生效的通行证，而是把选择拆为三个可分别核验的问题：

- 现有工作还有没有能换来下一段机会的空间；
- 全职准备的时间、钱与共同承担者能否撑住；
- 能否先在职拿到项目匹配、能力基线与真实负荷，再决定切换。

三条路线分别是“把工作做深”“辞职集中备考”和“在职验证再决定”。三幕的节奏也与创业场景不同：先核项目与生活条件，再交出申请/备考产出，最后决定是否切换或保留退出门。

## 如何体验

普通体验：从首页的“推演读研选择”进入，地址为 `/calibrate?scenario=graduate-school`。完成五项约束校准后，证据熔炉会展示该场景专属的知乎经验卡，并让用户选择一条路线。

稳定演示：打开 `/demo?scenario=graduate-school`。固定路线会选择“在职验证再决定”，依次完成：

1. 查清三个目标项目的硬门槛；
2. 写一页转向说明；
3. 检验“拿到学位，就能打开想去的赛道”；
4. 提交申请，同时保留工作选项；
5. 进入“在职验证再决定七天现实核验”。

固定演示只为了便于重复讲解；普通入口会创建新的本地会话。

## 证据边界

场景使用六条人工阅读的知乎社区内容。每张卡保留原文链接、作者显示名、条件、后果和审核说明。它们只用于提出待核验的问题：例如“学位是否真是目标岗位门槛”“项目是否有实践连接”“收入中断由谁承担”。

这些经验不是招生政策、薪资统计、录取预测或职业建议。尤其是招生资格、时间节点和项目规则，用户仍需以当年的官方简章为准。

## 与创业场景的泛化检查

| 维度     | 创业邀请                       | 读研选择                           |
| -------- | ------------------------------ | ---------------------------------- |
| 核心冲突 | 收入与熟人邀请、股权和现金流   | 职业连续性、学习投入与项目匹配     |
| 三条路线 | 留守 / 全押 / 搭桥试水         | 工作深化 / 集中备考 / 在职验证     |
| 关键假设 | 口头股权和资源是否兑现         | 学位是否真能打开目标赛道           |
| 现实实验 | 合同、客户、现金跑道与家庭负荷 | 简章、能力基线、申请产出与学习负荷 |
| 证据提醒 | 不把关系当合同                 | 不把学位名称当结果                 |

代码层面，两者共用同一个 `ScenarioPack` 合同、规则引擎与报告路由；会话中的 `scenarioId` 决定加载哪一个审核包。因此不能靠 URL 标题猜场景，也不会把创业行动带进读研报告。
