# TASK-028 研究资料索引

按下面顺序使用：

1. [`RESEARCH-PLAN.md`](RESEARCH-PLAN.md)：确认样本、流程、招募文案和结论门槛。
2. [`INTERVIEW-GUIDE.md`](INTERVIEW-GUIDE.md)：先完成真实经历访谈。
3. [`USABILITY-PROTOCOL.md`](USABILITY-PROTOCOL.md)：再进行无讲解产品测试。
4. [`SESSION-TEMPLATE.md`](SESSION-TEMPLATE.md)：每名参与者复制一份脱敏记录。
5. [`BASELINE.md`](BASELINE.md)：查看研究开始前已经确认和仍然缺失的信息。
6. [`SECONDARY-RESEARCH.md`](SECONDARY-RESEARCH.md)：查阅公开真实资料形成的待验证假设，不计入真人样本。
7. [`PROXY-REVIEW.md`](PROXY-REVIEW.md)：查阅多代理的证据支撑走查，用于聚焦真人测试；不计入真人样本。
8. [`FINDINGS.md`](FINDINGS.md)：样本完成后汇总重复痛点、严重问题和指标基线。

原始录音、联系方式和未脱敏材料不要放进仓库。可以把已脱敏记录保存到 `sessions/PXX.md`；如果不希望公开原话，只在本地保存记录，并在 `FINDINGS.md` 使用匿名编号和概括。
