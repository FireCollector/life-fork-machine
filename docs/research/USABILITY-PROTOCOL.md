# TASK-028 无讲解可用性测试

## 测试目标

观察第一次接触产品的人能否独立完成主流程，并正确理解产品边界。测试的是产品，不是参与者。

## 环境

- 优先使用参与者自己的电脑和常用浏览器；
- 浏览器缩放 100%，清除本项目旧存档；
- 从首页开始；若只验证固定链路，使用 `/demo` 并在记录中标明；
- 研究者看得到屏幕，但不控制鼠标；
- 不提前展示 README、讲稿或功能说明。

## 开场任务

> 假设你的直属领导邀请你离开一份稳定工作，加入他准备创办的新公司。请使用这个产品梳理这件事。过程中把你看到什么、以为会发生什么、为什么点击说出来。除非页面无法继续，否则我不会解释功能。

## 任务与观察点

| 任务         | 完成标准               | 观察内容                             |
| ------------ | ---------------------- | ------------------------------------ |
| 开始体验     | 进入校准或固定推演     | 首次点击时间；是否理解两个入口       |
| 选一条路线   | 进入第一幕             | 是否认为某条路线是系统推荐           |
| 完成第一幕   | 看到结果和分岔回声     | 是否看见收益与代价；是否打开其他世界 |
| 完成想法检验 | 选择假设和证据结果     | 是否理解支持、冲突和暂不清楚         |
| 查看报告     | 能说出得到、失去和未知 | 是否把雷达图当成评分或成功率         |
| 启动实验     | 找到并开始七天实验     | 是否理解它验证什么；是否注意退出条件 |
| 分享结果     | 找到分享摘要           | 是否担心隐私；是否觉得上下文完整     |

## 提示规则

- 前 90 秒不提示；
- 参与者询问“该选哪个”时，只回答“请按你现在的理解继续”；
- 90 秒仍无法继续时，只指出页面区域，不告诉具体按钮；
- 每次提示记录时间、原话和提示内容；
- 接受提示后可以继续观察，但该任务记为“提示后完成”。

## 任务后复述

不回看页面，依次问：

1. 这个产品最后想帮你得到什么？
2. 分岔回声代表什么？
3. “暂时不清楚”和“证据冲突”有什么区别？
4. 雷达图里的高低是不是成功率？
5. 七天实验要验证什么？完成后会怎样？
6. 系统有没有替你选择一条最好路线？
7. 如果明天真的要做决定，你会不会执行刚才的实验？为什么？

## 记录等级

| 等级       | 含义                                       |
| ---------- | ------------------------------------------ |
| 独立完成   | 无提示完成任务，并能正确复述               |
| 部分完成   | 能操作，但解释存在遗漏                     |
| 提示后完成 | 需要研究者指出方向                         |
| 误解完成   | 完成点击，但把预测、评分或演示当成真实结论 |
| 未完成     | 无法继续或主动退出                         |

## 严重问题

出现以下情况立即单独标记：

- 把情景叙事当作现实预测；
- 认为系统已经推荐了最佳选择；
- 页面无法恢复或记录丢失；
- 分享内容暴露参与者不希望公开的信息；
- 在没有理解验证目标的情况下启动实验。
