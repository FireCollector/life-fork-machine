# TASK-028｜证据支撑的代理可用性走查

日期：2026-09-07  
性质：预研究材料，不是用户测试

本走查由多个代理基于当前仓库、产品文档与公开资料完成。它没有招募真人、没有录制会话，也没有使用或伪造任何“用户原话”。它的作用是提前发现风险、把真人测试时间用在关键问题上；**不计入 8 位真实访谈或 5 位无讲解测试。**

## 标记

- `[D]` 当前代码、内容包或产品文档中的可核查事实；
- `[S]` [OECD 成人职业指导报告](https://www.oecd.org/en/publications/career-guidance-for-adults-in-a-changing-world-of-work_9a94bfad-en.html)、[职业不安全感研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8545860/) 和公开知乎讨论带来的设计启发；
- `[P]` 代理基于产品行为的推断，不能当作真人结论。

## 五个代理画像

### 01｜有共同支出的人

**处境**：31 岁，收入尚可，和伴侣共同承担房贷；领导邀请其降薪加入早期团队。

- **可能价值**：共同承担者、现金安全垫和家庭红线能把焦虑变成具体问题；七天实验已有最低支出、照护责任和退出红线。[D]
- **风险**：五题校准会影响后续，但用户不一定看得见“我的共同支出改变了什么”。它可能被误解为人格测试。[D][P]
- **待测改进**：进入世界线前展示“你的约束怎样影响本局”，例如将家庭现金流、投入时间和退出条件列为优先核验项；不显示路线分数。[P]

### 02｜担心错过成长窗口的人

**处境**：27 岁，现金储备较足，认可领导能力，担心留在原公司会错过核心职位。

- **可能价值**：留守、全押、搭桥不是简单二选一；搭桥能比较先买信息与立即承诺的代价。[D]
- **风险**：固定 Demo 走搭桥路线，可能让用户以为系统偏好保守方案；分岔回声也可能被看成对未来的预测。[D][P]
- **待测改进**：每条路线先问“你今天想先承受哪一种代价？”并持续标注“情景对照，不是推荐或预测”。[P]

### 03｜对股权与来源敏感的人

**处境**：34 岁，技术管理者；被承诺 CTO 职位和股权，愿意研究条款但拒绝把社区观点当法律结论。

- **可能价值**：素材卡保留作者、原文、适用条件和审核备注，审核后才进入正式推演。[D]
- **风险**：他可能分不清个人经验、二次转述和可用于自己条款判断的材料；高风险词汇缺少“何时找专业人士”的清晰出口。[D][P]
- **待测改进**：统一三层标记：社区经验用于发现问题、用户材料用于判断自身事实、条款/税务/劳动法交由合格专业人士核验。[S][P]

### 04｜输入“读研还是工作”的人

**处境**：24 岁，考虑辞职读研，从首页点击“尝试其他议题”。

- **可能价值**：`/topic-lab` 可将任意文字拆成候选路线、假设和实验，方向符合长期产品定义。[D]
- **风险**：用户可能期待进入完整三幕，而当前候选结构无法进入正式推演；会觉得产品实际只支持创业邀请。[D][P]
- **待测改进**：入口明确写为“试用议题拆解器（暂不进入完整剧情）”，并优先建设第二完整场景“工作 vs 读研”。[P]

### 05｜时间紧、只想马上知道下一步的人

**处境**：29 岁，offer 或离职期限临近，愿意尝试工具，但没有耐心完成长流程。

- **可能价值**：固定 Demo 可快速展示闭环；正式路径声明约 5–7 分钟、无需登录、可退出。[D]
- **风险**：逐日记录、快速推进和演示反馈并存，可能把“演示推进”当成真实七天追踪；结果页信息密度也可能让用户无法说出下一步。[D][P]
- **待测改进**：报告首屏只展示“现在最需要核实什么”和一个动作；视觉上分开“演示推进”与“开始真实七天实验”，真实模式至少具备日期、提醒、缺失处理与复盘入口。[P]

## 建议优先验证的问题

| 优先级 | 风险                                           | 证据性质  | 真人研究任务                                                |
| ------ | ---------------------------------------------- | --------- | ----------------------------------------------------------- |
| P0     | 自由议题入口承诺高，完整推演目前只有创业场景。 | [D][P]    | 让 5 名参与者从首页开始，记录点击“其他议题”后的预期和落差。 |
| P0     | 七天实验的演示推进与真实记录边界不清。         | [D][P]    | 任务后问：会不会真的等七天、会保存什么、结束后发生什么？    |
| P1     | 校准影响不透明，可能像人格测试。               | [D][P]    | 比较显示/不显示约束回执后的理解。                           |
| P1     | 分岔回声和雷达图可能被读成预测或评分。         | [D][P]    | 不回看页面，要求解释它们分别表示什么。                      |
| P1     | 知乎内容可追溯，但高风险条款缺少专业核验出口。 | [D][S][P] | 让参与者判断一条股权建议能否直接照做，并说明理由。          |
| P2     | 搭桥试水可能被误读为系统推荐。                 | [D][P]    | Demo 后追问：系统推荐你选哪条路了吗？                       |
| P2     | 结果页信息密度影响首次理解。                   | [D][P]    | 记录报告停留、关键未知复述率和实验启动意愿。                |

## 使用结论

这些是待证伪的风险清单，不是“发现”。在真实会话中，任何被 3 名以上独立参与者支持的重复问题，才可以进入 `FINDINGS.md` 的正式结论表。
