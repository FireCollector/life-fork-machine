# TASK-028 研究前基线

日期：2026-09-07  
状态：仓库审计完成，尚无真实用户数据

## 已确认事实

- 当前正式可玩场景只有“稳定高薪还是跟领导创业”。
- 主流程包含约束校准、三条世界线、三幕选择、分岔回声、想法检验、代价报告、七天实验和分享摘要。
- `/demo` 使用固定种子和搭桥路线，适合重复演示。
- `/topic-lab` 可以接受任意文字，但只生成候选结构，不能进入完整三幕游戏。
- 知乎内容来自缓存快照和人工审核，不是每次会话实时检索。
- 当前核心体验没有真实 AI 调用。
- 会话保存在浏览器本地，没有产品分析埋点。
- 自动化测试能证明流程按规则运行，不能证明用户理解或愿意使用。

## 当前没有的数据

- 首页到开始体验的真实转化率；
- 校准、每一幕和报告的用户流失率；
- 用户是否理解分岔回声不是预测；
- 用户是否把雷达图误解为路线评分；
- 用户是否认为关键假设与自己的真实担心有关；
- 用户是否愿意执行、以及能否完成七天实验；
- 用户是否需要知乎原文，或只看摘要；
- 用户第二次遇到问题时是否会回来。

## 待验证假设

以下内容只是研究假设，不是用户结论：

| 编号 | 假设                                               | 可能证据                                       | 反证                                 |
| ---- | -------------------------------------------------- | ---------------------------------------------- | ------------------------------------ |
| H01  | 用户缺的不是更多建议，而是把冲突经验映射到自身约束 | 3 人以上描述“答案都对但不知道哪个适合我”       | 用户主要缺客观信息或专业意见         |
| H02  | 看见未选择路线能帮助用户理解机会成本               | 用户正确复述分岔回声，并指出一项此前忽略的代价 | 用户认为只是故事装饰或未来预测       |
| H03  | 找到关键假设比获得路线推荐更有价值                 | 用户能说出一项会改变决定的未知                 | 用户只想让系统直接给答案             |
| H04  | 七天实验能降低立即做大决定的压力                   | 用户愿意保存或真实执行一个实验                 | 用户认为实验过重、过慢或与决定无关   |
| H05  | 知乎来源能提高可信度和行动质量                     | 用户主动打开原文并用适用条件修正判断           | 来源存在但不被查看，或只增加信息负担 |

## 当前优先观察的问题

1. 首页的三个入口是否让首次用户犹豫。
2. 校准是否被误解为人格测评。
3. 分岔回声和想法检验的名称是否需要解释。
4. 报告信息量是否超过用户当下能处理的程度。
5. 演示用“快速推进”是否让用户误以为七天实验只是一段动画。

这些优先级来自产品审计，不得在完成真实研究前写成“用户痛点”。
