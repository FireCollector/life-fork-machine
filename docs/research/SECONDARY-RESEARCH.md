# TASK-028｜公开材料二手研究

日期：2026-09-07  
性质：桌面研究，不是访谈或可用性测试

## 怎么使用这份材料

这里的资料来自公开网页、论文、机构职业指导和公开社区讨论。它们用于发现值得验证的情境、设计研究问题和检查产品假设；**不代表《人生分岔机》已有真人用户结论**，不计入 TASK-028 的 8 份访谈或 5 份无讲解测试。

资料按证据强度区分：

- **A**：代表性调查或元分析，可用于理解一般规律，但不直接外推到中国目标用户；
- **B**：同行评审研究、权威机构职业指导或行业报告，可用于形成待验证假设；
- **C**：公开社区个案，可用于发现真实措辞和候选情境，不能统计或代表总体。

任何后续产品结论都要回到真实目标用户会话中确认。社区经验不能替代劳动、法律、税务或财务专业意见。

## 二手研究信号：不是用户结论

1. **用户比较的往往不是两个标签。** 收入、时间、成长、家庭责任、地点和职业连续性会同时出现。产品应先呈现“已知成本 / 未知成本 / 可验证项”，再比较路线。
2. **“逃离现在”不等于“适合去另一边”。** 转行、读研和跳槽讨论常把压力当动机。产品应追问离开动机，并生成低风险验证动作，而不是把新路径渲染成答案。
3. **价值排序与结果不确定应被分开处理。** 用户需要说明哪些条件不可妥协、什么结果最怕发生；继续堆资料未必能消除犹豫。
4. **高风险选择需要可逆实验。** 将“暂不清楚”转成带截止日期和产物的验证任务，符合公开职业指导中的小步行动方向。
5. **地点和支持网络是路径变量。** 跨城或创业不能只比较收入；岗位密度、居住成本、家庭支持和退路都应进入验证。

## 将在真实研究中检验的假设

| 编号 | 假设                                                                     | 最小验证方式                                                   |
| ---- | ------------------------------------------------------------------------ | -------------------------------------------------------------- |
| H06  | 显式呈现价值取舍和结果不确定，比继续浏览更多建议更能帮助用户说出下一步。 | 访谈后让参与者复述自己的一项取舍和一项未知。                   |
| H07  | 把工作质量拆成薪酬、成长、兴趣、生活和风险，能减少“总分替代取舍”的误解。 | 对比两种报告表达后的复述。                                     |
| H08  | 可逆、带产物的七天实验能提高开始验证的意愿。                             | 让参与者选择一项可在一周内完成的外部证据任务，并追踪是否启动。 |
| H09  | 社区讨论只适合提供候选情境；它们是否贴近中文目标用户，必须由真人确认。   | 访谈时不展示来源，先询问是否遇过相似约束。                     |

## 不可得出的结论

- 不能以这些来源声称“已经完成用户调研”或“用户一定需要本产品”。
- 不能将公开作者的文字改写成参与者原话。
- 不能用社区建议直接处理股权、劳动合同、税务、投资或心理健康等高风险问题。
