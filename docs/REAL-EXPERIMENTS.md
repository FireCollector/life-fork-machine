# TASK-038｜真实七天实验说明

## 两种模式

| 入口                                      | 模式 | 能做什么                                 | 不会做什么                                              |
| ----------------------------------------- | ---- | ---------------------------------------- | ------------------------------------------------------- |
| `/demo`、`/demo?scenario=graduate-school` | Demo | 快速推进七天，用于讲解完整闭环           | 不会被标成真实连续七天，也不会出现导出/删除真实记录入口 |
| 首页进入的普通推演                        | 真实 | 按日期记录、跳过、改期、停止、导出与删除 | 不提供一键完成七天                                      |

模式被写入每条实验会话的 `experimentRun.mode`，而不是仅靠页面 URL 判断。Demo 日志和真实日志在数据结构上可区分。

## 真实模式如何工作

开始当天解锁第 1 天。保存当天记录后，引擎写入下一条可用日期；在该日期之前，刷新页面、复制链接或回到报告都无法推进。每条日记包含：

- 采取的动作与文字记录；
- 证据类型：材料、沟通、观察、数字或其他；
- 当天感受：更清楚、稳定、吃力或被卡住；
- 明天最小一步；
- 完成或跳过状态，以及真实日期。

用户可以把未完成的一天改到今天或未来日期；也可以跳过当天并写下原因。遇到生活变化时，可提前停止实验，停止原因会保留在记录中，而不会伪装为完成或失败。

第 7 天后，用户选择“证据支持 / 证据冲突 / 暂时不清楚”。报告会把这个结论与三幕中最初的假设判断并排显示，提醒用户比较“原先怎么想”和“七天后拿到了什么”。

## 隐私与数据控制

记录默认仅保存于当前浏览器的 `localStorage`。用户可以：

- 导出本次实验为 JSON，内容包含场景、路线、假设前后状态、日期和自己的条目；不包含账号或存储键；
- 删除本次本地记录。删除前需要二次确认，且不会影响其他本地会话。

这不是云端同步，也不保证跨设备恢复；账号与云端隐私中心属于后续 TASK-044。

## 旧记录迁移

旧版本的实验没有 `mode` 和日期字段。读取时：固定 Demo 的旧记录迁移为 `demo`；普通旧记录迁移为 `real`，并以最后更新时间作为日期锚点。迁移不会把旧记录补成“已完成七天”，也不会自动生成缺失条目。
