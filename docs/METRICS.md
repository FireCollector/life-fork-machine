# 产品指标字典

版本：v1.0  
维护任务：TASK-027

## 北极星指标

### 有证据的下一步形成率

定义：在完成代价报告的有效会话中，用户确认至少一个关键未知，并启动或保存一个包含证据要求与退出条件的现实实验的比例。

```text
有证据的下一步形成率
= 完成关键未知确认且启动/保存实验的有效会话数
÷ 完成代价报告的有效会话数
```

它比“报告生成数”更接近产品价值，因为用户必须从观看故事走到现实行动。它也不要求用户接受某条系统路线。

第一轮目标：≥ 40%。在真实埋点上线前，TASK-028 先用人工观察记录替代。

## 核心漏斗

| 指标           | 定义                                     | 第一轮目标 | 当前基线             |
| -------------- | ---------------------------------------- | ---------: | -------------------- |
| 体验启动率     | 看到首页后进入校准或固定 Demo            |      ≥ 60% | 未采集               |
| 校准完成率     | 开始校准后完成全部问题                   |      ≥ 80% | 未采集               |
| 三幕完成率     | 进入第一幕后生成代价报告                 |      ≥ 65% | 未采集               |
| 关键未知复述率 | 测试后能用自己的话说出一个仍需核实的问题 |      ≥ 70% | 待 TASK-028 测量     |
| 来源使用率     | 完整体验中至少打开一次知乎原文或来源详情 |      ≥ 20% | 未采集               |
| 实验启动率     | 看完报告后开始或保存七天实验             |      ≥ 40% | 未采集               |
| 首日完成率     | 启动真实实验后完成第一天记录             |      ≥ 60% | 功能尚未区分真实模式 |
| 七日完成率     | 启动真实实验后完成第七天反馈             |      ≥ 25% | 功能尚未上线         |
| 30 日复盘率    | 到期用户完成一次决策复盘                 |      ≥ 20% | 功能尚未上线         |

## 质量护栏

| 指标             | 要求                                                  |
| ---------------- | ----------------------------------------------------- |
| 来源可追溯率     | 所有外部事实性内容都能回到来源，目标 100%             |
| 无证据事实率     | AI 生成但无来源支持的事实性陈述，目标 0               |
| 高风险议题拦截率 | 医疗、法律、投资等议题进入普通推演前被识别，目标 100% |
| 单边路线率       | 只有收益或只有代价的行动占比，目标 0                  |
| AI 降级成功率    | Provider 不可用时会话不丢失且可继续，目标 100%        |
| 分享隐私泄露     | 分享内容出现 session ID、账号或私人备注，目标 0       |

## 体验理解指标

TASK-028 通过访谈和任务后复述记录：

- 用户如何解释“分岔回声”；
- 用户能否区分证据支持、证据冲突和暂不清楚；
- 用户是否把雷达图误解为路线评分；
- 用户能否说出七天实验要验证什么；
- 用户是否知道最终决定仍由自己完成。

每项按 `理解 / 部分理解 / 误解` 记录，不用主观的“感觉不错”代替。

## 隐私约束

- 默认不上传用户输入的困境原文、每日备注和身份信息。
- 分析事件只使用匿名会话标识、枚举值和区间值。
- 自由文本如需用于产品研究，必须单独征得同意并支持删除。
- 不使用精确收入、单位、学校或联系人作为分析属性。
- Demo 模式与真实用户模式分开统计。

## 指标解释规则

- 先看用户是否理解，再看是否完成点击。
- 完成率提高但误解率上升，不视为成功。
- 实验启动率高但首日完成率低，优先检查实验是否过重。
- 来源点击低不一定代表来源没价值，需要结合用户是否在卡片内已经获得足够信息。
- 指标只用于改进体验，不用于给用户打分或推断人格。
