# 候选 ScenarioPack v2

`TASK-034` 将“已确认的问题 + 本次知乎来源”编译成一个**待审核**的三世界候选剧本。它不是当前固定 Demo 的替代品，也不能直接进入游戏引擎。

## 体验路径

在 `/topic-lab` 中完成：确认决策简报 → 获取知乎候选 → 整理观点 → 点击“生成候选三幕”。页面会展示三条路线，每条路线的三幕、每幕三个可执行动作，以及动作的时间/金钱上限。

## 两种来源标记

- `ai-assisted`：服务端 AI 候选已通过既有结构与来源引用校验后，再被编译为场景草稿。
- `rules-assisted`：实时 AI 不可用或输出不合格时，系统只根据**本次检索来源**和用户已确认的未知项生成透明草稿。

两种模式都不是发布内容。页面会显示原因，且发布按钮保持禁用。

## 强制门禁

Candidate ScenarioPack 强制要求：

- 恰好三条世界线，每条恰好三幕，每幕恰好三个动作；
- 所有外部经验对应的 `sourceId` 必须属于本次检索来源；
- 动作时间限制在 5–480 分钟，金钱上限在 0–2000 元；
- 世界、幕和动作 ID 不能重复；
- `review.status` 固定为 `needs-editor-review`，`publicationAllowed` 永远为 `false`。

TASK-035 只会消费经过人工审核的候选文本；正式 ScenarioPack 仍需再通过现有游戏 Schema、数值和发布版本流程。
