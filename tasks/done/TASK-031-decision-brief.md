## 目标

让用户先把一个普通生活选择说清楚：系统提取选项、期限、角色、约束、不可逆成本、未知项和隐含假设；用户可编辑确认后，才把简报交给后续的知乎检索与候选场景流程。

## 范围

- 允许修改：`src/features/decision-brief/**`、Topic Lab 相关页面/组件、`tests/**`、任务与验证文档、README/架构说明。
- 不允许修改：规则引擎、正式 `ScenarioPack`、真实知乎检索、自动发布、浏览器直连模型或保存真实敏感文本。
- 本任务不做：TASK-032 的来源拉取、TASK-033 的证据聚类、TASK-034 的剧情生成。

## 交付物

- `DecisionBrief`、澄清问题与安全处理的 Zod Schema；
- 可解释的本地初步解析器与可替换的 AI 候选入口；
- 输入、必要追问、编辑确认、临时保存与继续入口；
- 高风险议题的停止/安全指引；
- 至少 20 条未预置议题的测试样本与质量汇总。

## 验收标准

- [x] 普通职业、升学、搬家和关系议题可得到可编辑简报，不直接推荐路线。
- [x] 模糊问题最多提出 1–3 个必要追问，信息足够时不强行追问。
- [x] 高风险议题不进入普通推演，并显示明确的安全处理说明。
- [x] 用户修改后能恢复同一份简报；未经确认不进入后续检索。
- [x] 至少 20 条隐藏议题中 ≥80% 通过结构与人工可读性检查。
- [x] lint、typecheck、测试、build 与验证报告全部通过。
