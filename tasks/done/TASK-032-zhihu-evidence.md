# TASK-032｜建立动态知乎证据检索管线

- 状态：Verification
- 依赖：TASK-031 Done
- 目标：从已确认的 `DecisionBrief` 生成多组检索词，经官方知乎 CLI 获取可追溯候选来源；服务端处理缓存、去重、失败与审核边界。

## 已确认的起点

- 官方 `zhihu-cli` 0.5.0 已验证，Access Secret 位于系统钥匙串。
- `search zhihu` 能返回内容 ID、作者、摘要、原文链接、互动数据与排序分。
- 现有实现仅能把单一命令输出写成静态快照，尚未由 `DecisionBrief` 驱动，也没有服务端缓存和失败状态。

## 本任务范围

- [x] 生成 2–4 组检索词，不把用户原句作为唯一查询。
- [x] 建立服务端检索、限流、去重、TTL 缓存与透明失败结果。
- [x] 保存内容 ID、作者、链接、抓取时间、互动数据和检索词；只保存摘要，不复制全文。
- [x] 将结果标为待审核候选，不自动批准或生成事实结论。
- [x] 对真实创业议题完成官方检索验证；空结果、限流和不可用状态均有透明返回，不以旧结果冒充实时内容。
