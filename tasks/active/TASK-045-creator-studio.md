# TASK-045｜场景编辑与内容运营后台

- 状态：Verification（等待 Supabase 迁移与角色授权）
- 依赖：TASK-034、TASK-044 Done
- 目标：让具备 Creator 角色的非开发者可导入候选场景、编辑 JSON 草稿、看到 AI 初稿差异和校验结果，并按草稿、审核、发布、下线流程管理不可变版本。

## 范围

- Creator Studio 页面、Supabase 角色与内容版本模型。
- AI 初稿与人工修改差异、Schema/来源/重复与发布门禁检查。
- 草稿、审核、发布、下线及审计记录。
- 候选场景从议题实验室复制到 Studio 的安全交接。

## 不在范围

- 不把已发布 Candidate ScenarioPack 直接替换正在运行的玩家会话；旧会话继续持有自己的完整快照。
- 不为数据库创建 service-role 密钥或绕过 Row Level Security。

## 验收

- 角色外用户不能写入内容版本。
- 编辑者可以完成导入、校验、提交审核；发布者可以发布/下线且留下审计记录。
- 每次发布生成独立版本，历史版本不可被覆盖。
