# D01 最小数据接通验收记录

## 结论

D01 已完成。S02 知乎证据包、S03 三幕剧本和结果模板现在通过同一个 Zod 校验入口加载，后续规则引擎与页面可以直接消费稳定的 TypeScript 类型。

## 数据合同

- 六维状态值严格限制在 `0–100`，行动变化量限制在 `-100–100`。
- 场景固定包含 `stay`、`leap`、`bridge` 三个世界。
- 每个世界固定三幕，每幕固定三个行动。
- 每个场景只允许指向另外两个世界的分岔回声。
- 知乎来源仅允许官方问答与专栏 URL，证据 ID 遵循 `zh-startup-XX`。
- 行动必须同时描述收益、代价，并至少写入事实、承诺或不可逆事件之一。
- 会话状态带版本、阶段、校准答案、六维状态、承诺账本、历史、随机种子和时间戳。

## 统一入口

`src/features/game/index.ts` 对外统一导出：

- 经过验证的 `demoContent`；
- `contentStats`；
- `parseDemoContent`；
- 所有核心 Schema 与 TypeScript 类型。

原始 JSON 加载时立即校验。内容结构错误会抛出 ZodError；跨文件 source ID 或 action ID 错误会抛出 `DemoContentReferenceError`，避免错误延迟到用户游玩时才出现。

## 测试覆盖

- 当前 S02/S03 内容正常加载。
- 必填字段缺失会失败。
- 六维状态超出范围会失败。
- 引用不存在的知乎来源会失败。
- 结果模板引用不存在的行动会失败。

## 阶段边界

D01 只建立数据合同和读取层，不改变 UI，也不实现行动计算、会话持久化或结果计算；这些工作进入 D02–D06。
