# D03 校准与证据熔炉验收记录

## 结论

D03 已完成。首页之后的校准与证据熔炉不再是静态骨架：用户可以完成五项约束校准、查看可解释的六维修正、浏览 8 张真实知乎证据、筛选三类相反立场，并从三个世界中创建一个匿名本地会话进入游戏。

## 五步校准

- 五个问题均使用真实选项，并支持前进、后退和修改答案。
- 未选择当前问题时禁止继续，完整回答后才能进入证据熔炉。
- 进度条、当前题数和已回答数量实时更新。
- 完成后展示六维修正，不输出人格标签或最佳路径。
- 身心负荷使用相反的风险语义，避免把“数值升高”错误渲染为正向变化。
- 已完成校准使用版本化浏览器存储保存，返回页面时可以继续修改。

## 证据熔炉

- 依次展示“读取真实经历 → 拆出观点与条件 → 编译平行人生”三阶段过程。
- 明确说明证据获取日期、知乎官方 API 来源、人工审核缓存及非实时状态。
- 展示全部 8 张证据卡，包括标题、作者、内容类型、观点转述、适用条件、赞同数和原文链接。
- 可以按支持行动、反对冒进和条件成立三类立场筛选。
- 原文链接只指向 `www.zhihu.com` 或 `zhuanlan.zhihu.com`，并在新窗口打开。

## 三世界入口

- 留守轨道、全押新局、搭桥试水均展示各自起点和结构性代价。
- 页面明确说明选择世界不是系统推荐，未选路径之后仍以分岔回声出现。
- 点击任一世界后，调用 D02 引擎创建并初始化匿名会话。
- 会话以版本化、按 session ID 隔离的 key 写入 `localStorage`，然后跳转至真实动态路由 `/play/{sessionId}`。
- 缺少完整校准时禁用世界入口，并给出返回校准的明确恢复动作。

## 存储安全

- 校准与会话在写入前均经过 Zod 校验。
- 读取到损坏或过期结构时，只清除对应 key，不影响其他会话。
- 本地内容不包含 OAuth、知乎 Access Secret 或个人身份信息。
- React 客户端通过 `useSyncExternalStore` 读取浏览器存储，避免服务端首屏水合闪烁。

## 自动化测试

新增 5 项测试：

- 校准数据往返保存。
- 损坏校准数据自动隔离。
- 匿名会话按 ID 独立保存。
- 五步校准、返回修改、结果展示和熔炉跳转。
- 8 张证据、三个世界及搭桥会话创建。

全项目当前共 26 项 Vitest 测试。

## 阶段边界

D03 只负责创建会话并进入游戏。三幕行动按钮仍由 D04 接入规则引擎，刷新恢复、后果模板和完整三幕闭环也属于 D04。
