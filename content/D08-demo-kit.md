## 演示前 30 秒检查

1. 在项目目录运行 `npm run dev`。
2. 打开 `/demo`，确认自动进入“承诺之夜：先试四周，别急着辞职”。
3. 确认顶部显示 `SESSION DEMO-BRI`，状态栏显示“本地存档已同步”。
4. 浏览器缩放保持 100%，桌面演示建议宽度不低于 1280px。

## 固定点击路线

1. 第一幕：选择“把四周要查的事写下来”。
2. 分岔回声：指向另外两条世界，然后点击“进入第 2 幕”。
3. 第二幕：选择“条件谈妥，再正式加入”，再点击“进入第 3 幕”。
4. 想法检验：选择“领导真会把股权给你”。
5. 验证线索选择“合同里没有”，查看反转结果。
6. 点击“继续下一步”。
7. 第三幕：选择“条件都过关，正式加入”。
8. 点击“生成代价报告”。
9. 在结果页依次指向雷达图、得到/失去/仍不知道、7 天现实实验。

如果现场时间不足，可以使用“直接下一步”与“直接看结果”；不要跳过假设选择本身。

## 队友常见追问

### 它是不是替用户做职业选择？

不是。系统从不展示最佳答案或成功概率，只展开收益、代价、未知与证据边界。

### 知乎内容是真实的吗？

Demo 使用 8 条由知乎官方 API 获取并人工审核的缓存证据，保留原文链接、作者、立场和适用条件；当前不是实时搜索。

### 为什么目前只有一个议题？

当前阶段冻结一个高质量困境以证明核心机制。数据模型已经把场景、世界、行动、证据和结果模板分离，冲刺阶段可接入场景生成管线。

### 为什么不用在线 AI？

队友 Demo 优先保证稳定和可复现，因此数值由确定性规则引擎计算，叙事来自审核模板。在线个性化属于冲刺阶段增强项。

## 已知边界

- 当前仅有“稳定高薪工作与跟领导创业”一个冻结场景。
- 无 OAuth、无登录、无云端同步；会话只保存在当前浏览器 `localStorage`。
- 知乎证据为人工审核缓存，不宣称实时检索。
- 结果中的未来来信是情景反思文本，不是预测。
- 固定 `/demo` 入口会重置 `demo-bridge-v1`，不应用于保存个人长期进度。
