# S05 设计系统与页面骨架验收记录

## 结论

S05 已完成。五条产品路由已建立统一视觉系统、桌面/移动公共布局、全局导航、加载/空/错误状态和 reduced-motion 降级，并通过真实浏览器三档响应式验收。

## 视觉系统

视觉方向为“深夜里的决策实验室”，避免普通 AI 对话框或通用仪表盘外观：

- **品牌主色**：知乎蓝 `--zhihu-blue`，用于当前进度、主行动与可信来源标识。
- **深夜场域**：`--night`、`--night-raised`，配合低对比网格和局部蓝紫光晕。
- **三条世界色**：留守轨道 `--world-stay`、全押新局 `--world-leap`、搭桥试水 `--world-bridge`。
- **语义色**：现实实验/可继续状态使用 `--signal-lime`，破坏性状态使用 `--destructive`。
- **字体**：无外部字体请求，使用 Inter / HarmonyOS Sans SC / PingFang SC / Microsoft YaHei 系统回退栈；展示标题使用收窄字面回退栈。
- **尺寸系统**：基础圆角 `0.875rem`、面板圆角 `1.5rem`，统一使用 4/6/8 的响应式间距节奏。
- **阴影**：`--shadow-panel` 用于悬浮深夜面板，`--shadow-blue` 用于关键入口，不使用大面积高亮。
- **动画**：160ms / 280ms / 620ms 三档时长和统一 ease-out；减少动态效果时降至 0.01ms。

## 公共布局

- 桌面端使用粘性顶部导航，包含困境、校准、熔炉、推演和报告五个入口。
- 低于 `lg` 断点时切换为固定底部五项导航；顶部仅保留 Logo、产品名和重新开始。
- 全站固定显示“不是预测/社区经验样本”免责声明以及匿名本地、无 OAuth 状态。
- Logo 由三条分岔轨道组成，直接对应产品核心机制。
- 页面主体最大宽度为 90rem，小屏从 320px 起支持，无横向滚动。

## 五条路由

| 路由                  | 页面职责     | 当前骨架内容                                                      |
| --------------------- | ------------ | ----------------------------------------------------------------- |
| `/`                   | 单一强入口   | 核心命题、唯一困境卡、三条世界、一次点击进入校准                  |
| `/calibrate`          | 五项约束校准 | 1/5 进度、现金安全问题、选项布局、空校准结果                      |
| `/forge`              | 证据熔炉     | 三步编译管线、缓存/获取时间说明、空证据卡状态                     |
| `/play/[sessionId]`   | 三幕游戏     | 桌面三栏/移动单列、场景、三行动、三轨时间线、六维状态、空证据抽屉 |
| `/result/[sessionId]` | 结果报告     | 三世界雷达占位、得到/失去/未知、空未来信、7 天实验与分享占位      |

动态路由会拒绝包含非法字符的 session ID，并显示各自的 not-found 空状态。

## 状态与无障碍

- 根路由及体验路由组均提供 `loading.tsx` 和 `error.tsx`。
- 错误页是最小 Client Component，支持重试和返回入口；静态空状态仍为 Server Component。
- 动态会话提供 not-found 状态，不会伪造不存在的会话或结果。
- 加载状态使用 `aria-busy`、`aria-live`；导航使用 `aria-current`；装饰图标均隐藏于辅助技术。
- 所有交互元素有键盘焦点环，主要按钮和导航满足最小触控高度。
- `prefers-reduced-motion: reduce` 会关闭滚动动画、转场和无限动画。
