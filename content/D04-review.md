# D04 三幕可玩闭环验收记录

## 结论

D04 已完成。留守、全押与搭桥三个世界都消费同一套强类型场景和确定性规则引擎；任意世界均可连续执行三幕行动，行动后立即写入六维状态、承诺账本和进度，并在第三幕完成后进入与真实本地会话对应的结果页。

## 三幕体验

- 动态路由 `/play/{sessionId}` 只读取经过 Zod 校验的版本化本地会话，不根据 URL 伪造进度。
- 当前世界的三幕均展示冻结内容中的 3 个真实行动，以及当前场景或行动对应的 1–2 张知乎证据卡。
- 行动提交后由 D02 引擎确定性结算六维变化，并同步写入收益、代价、事实、承诺、不可逆事件和行动历史。
- 每次结算均展示冻结模板中的行动后果，避免网络或生成模型波动影响队友演示。
- 第一、二幕后需明确进入下一幕；第三幕完成后才允许生成结果。

## 会话恢复与状态边界

- 新增基于 `useSyncExternalStore` 的本地会话订阅，监听浏览器 `storage` 事件和应用内自定义更新事件。
- 页面刷新后使用 session ID 恢复世界、幕次、状态、账本、行动历史及已爆破假设。
- 不存在或结构损坏的会话显示恢复入口，不创建伪造会话。
- 已完成会话再次打开时，可直接进入其真实结果页。

## 假设爆破门槛

D02 规则要求第三幕前必须完成一次假设爆破。D04 已接入可用的最小交互：第二幕结算后选择一个关键前提、查看冻结反转叙事，再进入第三幕。D05 将在此基础上增加舞台化动效、分岔回声以及减少动态效果支持。

## 结果页

- 结果页读取完成态会话并展示实际选择的世界，不再固定展示某一条路径。
- 展示用户实际走过的六维状态、行动账本和已爆破假设。
- 未完成会话不会生成结果，只提供返回推演入口。
- 三世界雷达、未来信和 7 天实验仍按计划留给 D06；当前页面明确标注该阶段边界。

## 自动化测试

新增 4 项组件测试：

- 第一幕行动、模板后果与本地持久化。
- 卸载并重新挂载后的第二幕恢复，以及行动 → 假设爆破 → 第三幕 → 结果跳转完整闭环。
- 缺失会话不被伪造。
- 完成态结果读取真实世界与账本，未完成会话不得生成结果。

全项目当前共 30 项 Vitest 测试，10 个测试文件全部通过；TypeScript 类型检查与 ESLint 均通过。

## 真实浏览器验收

使用内置浏览器完整走通一次搭桥世界：

```text
五项校准 → 8 张证据 → 选择搭桥试水 → 第一幕行动
→ 进入第二幕 → 刷新页面并恢复 → 第二幕行动
→ 假设爆破 → 第三幕行动 → 动态结果页
```

验收结果：

- 第一幕展示 3 个行动和 2 张知乎证据，结算后状态增量与账本即时更新。
- 第二幕刷新后仍停留在正确场景，并保留第一幕行动。
- 假设爆破后才允许进入第三幕。
- 结果页显示“搭桥试水的三幕已经完成”、3 个行动、真实账本及所选假设。
- 浏览器控制台 0 errors。
- 360 × 800 与 1440 × 900 视口均无横向溢出。

## 阶段边界

D04 负责稳定、可恢复的三幕核心循环。D05 负责把现有最小假设爆破升级为舞台化记忆点，并补充另外两个世界在同一时刻的分岔回声。
