# S02 知乎证据内容包审核记录

> 场景：高薪留任还是跟领导创业  
> 执行日期：2026-09-01  
> 来源：知乎开放平台官方 Skill / CLI 0.5.0

## 1. 查询计划

设计了五组互补查询：

1. `跟领导辞职创业 要不要 股权 合伙 真实经历`
2. `加入创业公司 股权 口头承诺 创始团队 踩坑`
3. `辞职创业 现金流 家庭 伴侣 压力 真实经历`
4. `创业失败 回大厂 找工作 职业选择 真实经历`
5. `在职验证 创业项目 兼职 试水 再辞职`

并行请求触发官方 `Code 30001` 频率限制后立即停止，没有循环重试。冷却后仅执行一次合并查询：

`辞职加入创业公司 股权承诺 现金流 家庭压力 创业失败 在职试水 真实经历`

最终证据包只使用这次成功保留的官方响应，未使用搜索引擎摘要代替知乎内容。

## 2. 去重和筛选规则

- 先按 `ContentID` 和规范化 URL 去重。
- 同一问题下不同作者的回答视为独立内容，但必须保留各自作者和立场。
- 删除广告、纯口号、只有情绪而没有条件—行动—结果链条的内容。
- 优先保留与主场景直接相关、能映射到游戏变量或假设爆破的内容。
- 不以点赞数单独决定保留；低互动内容必须添加谨慎使用标记。
- 最终保留 8 张卡、8 位作者、8 个唯一 ContentID 和 URL。

## 3. 覆盖矩阵

| 类别                         | 证据卡                                  | 用途                                   |
| ---------------------------- | --------------------------------------- | -------------------------------------- |
| 支持创业及其潜在收益         | `zh-startup-02`、`05`、`08`             | 成长、自主、双轨现金流；全部带适用条件 |
| 反对直接裸辞或情绪性创业     | `zh-startup-01`、`06`、`07`             | 家庭风险、债务、平台依赖和情绪决策     |
| 支持先验证、谈条件或组合策略 | `zh-startup-01`、`02`、`03`、`07`       | 搭桥试水、尽职调查、书面条款           |
| 股权、现金流和团队关系       | `zh-startup-01`、`04`、`06`、`07`、`08` | 股权谈判、欠薪预警、合伙协议、扩张风险 |

同一证据可以覆盖多个类别。这里的“支持创业”指展示有条件的正向可能，不代表建议所有用户创业。

## 4. 链接检查

- 所有 URL 均为官方 API 返回的 HTTPS 知乎回答或文章地址。
- 8 个 URL 的域名、内容类型和 ContentID 结构均通过检查。
- 自动公开抓取收到知乎 403；应用内浏览器验证又受到当前网络连接重置影响。这是访问环境限制，不等同于链接失效。
- 开发阶段保留官方 API 原始 URL；进入 S14 前必须在比赛网络和登录浏览器中再次逐条人工点击验收。

## 5. 质量与事实边界

这些材料的共同限制：

- 是社区经验和观点，不是代表性样本、统计研究或因果证明。
- 多数内容互动量较低、发布时间较新，不能据此生成成功率或失败率。
- `zh-startup-02` 是二次转述，只能作为策略样本。
- `zh-startup-05` 是机构发布的成功个案，存在明显选择偏差。
- `zh-startup-04` 涉及劳动法和仲裁叙述，项目不验证法律结论，也不提供法律建议。
- 第一人称内容的真实性没有被项目独立核验，产品必须显示“知乎社区经验”而不是“事实证明”。

因此所有卡统一标记为 `community_experience_for_scenario_only`，只能用于：

1. 生成可能发生的情景；
2. 暴露用户需要核验的假设；
3. 构造收益与代价；
4. 提供可点击的进一步阅读入口。

不得用于：

1. 推断个人未来；
2. 输出概率或成功率；
3. 替代法律、财务、医疗等专业建议；
4. 把一个作者的经历推广为所有创业者的规律。

## 6. 文件产物

- `source-cards.json`：8 张结构化证据卡，可供 S03 内容规则和 S06 Schema 使用。
- 本审核记录：保存查询、筛选、覆盖和风险边界。

## 7. S02 结论

S02 内容包可以支持主场景第一版三幕设计。由于当前链接外部访问环境受限，链接将在 S14 发布验收阶段再次点击检查；这不阻断 S03 使用官方 API 已返回的内容与规范化 URL。
