# D12 七天现实实验展示验收记录

## 目标

把结果页的“七天现实实验”从一张行动清单升级为可执行、可判断的现实验证卡。用户需要知道要验证什么、为什么现在验证、如何取证，以及不同结果会怎样影响下一步。

## 已完成

- 扩展 `sevenDayExperiments` 数据契约，新增 `question`、`whyNow`、`evidence` 和 `resultMeaning` 三结果说明。
- 为创业议题的 9 个实验模板补齐上述字段，保持每条实验都有三步、时间/花费上限和退出规则。
- 结果页新增“要验证什么”“为什么现在查”“七天怎么做”“什么算证据”。
- 结果页新增三种结果含义：证据支持、证据冲突、暂时不清楚。
- 将预算口径改成“时间上限”“花费上限”，避免把实验误解为必须花完的预算。
- 复制文本结果同步包含验证问题、取证标准和三种结果解释，队友可直接复制查看完整实验卡。
- 页面保留“实验只是行动建议，不会自动执行，也不是对未来的预测”的说明。

## 验收结果

- `npm run validate:s03` 通过：9 个实验模板均完成新字段校验。
- `npm run typecheck` 通过。
- `npm run lint` 通过。

- `npm run build` 通过。
- 固定 Demo 已走到结果页，桌面端确认实验卡信息层级和布局正常。

## 有意留到 D13 的内容

- 实验反馈仍是展示型文案，尚未提供“支持 / 推翻 / 暂时无结论”的可点击模拟反馈。
- 暂不接入真实七天计时、通知或后台跟踪，避免 Demo 让用户误以为系统已在现实中执行实验。
