## 发现并修复的评测安全问题

首次调试暴露出 Windows PowerShell 对无 BOM 中文 JSON 的读取风险：高风险样例可能在脚本层变形，进而错过关键词识别。该样例不含真实个人数据，但不应发给模型。现已修复：

1. 使用显式 UTF-8 解码读取隐藏集；
2. 按 `high-risk` 标签或 `expectedSafety: stop` 在构造请求前本地停止；
3. 高风险题只记录 `sensitive-topic` 结果，不再调用 Provider。

该防护与已有服务端敏感主题拦截叠加，避免评测工具成为绕过安全边界的入口。
